# جعبهٔ ابزار پژوهش: نشانه‌شناسی زبان بدن (دو مقاله)

> راهنمای کامل: ساختار، گردش‌کار پژوهش و همهٔ دستورات. همهٔ ابزارها با Python 3.15 اجرا می‌شوند.
> جهت‌دهی فارسی RTL در همهٔ خروجی‌ها (xlsx, docx) رعایت شده است.

## ۲. کتاب‌کد ماتریسی (codebook) — «کالبد در موقعیت» (مقالهٔ اول)

هفت مقولهٔ ماتریسی، هرکدام با زیرمحورهای هندسی/ساختاری. کلید: زبان بدن به‌مثابهٔ متن دیداری خودبسنده، فارغ از گفتار.

| مقوله | کلید | زیرمحورها | مثال |
|---|---|---|---|
| بردار نگاه (Gaze Vector) | G | محور + پایداری + کنش | G1a افقی مستقیم، G2a خیره >4ث، G3a Demand |
| ریزآرایش چهره (Facial Micro) | F | گلابلا + ابرو + لب/فک | F1a چین انقباضی، F2c گره‌خورده، F3b تبسم گشوده |
| انحراف محوری سر (Head) | H | شیب جانبی + محور قائم | H1b متمایل به شانه، H2a افراشته |
| راستای ستون فقرات (Torso) | T | زاویهٔ تنه + جهت‌گیری جبهه | T1b مایل جلو (تقرب)، T2b زاویه‌دار (Oblique) |
| دست چپ — کنش‌گر (Agent Hand) | L | دامنهٔ فضایی + فرم پنجه | L1a محصور مرکزی، L2d اشاره سبابه، L2e گرفتن عصا |
| دست راست — تکیه‌گاه (Support) | R | وضعیت ثبات | R2 ثابت روی دسته، R4 مهارشده زیر عبا |
| مرزبندی پوشش (Framing) | C | فرم عبا + پیرایه‌ها | C1a جمع‌شده (تحدید)، C1b رها (توسعه)، C2g تقابل روحانی/نظامی |

**اصل کلیدی:** کد، صرفا‌توصیف هندسی/ساختاریِ نشانهٔ قابل‌مشاهده است. *دلالت* (شفقت نمادین، صلابت نهادی، اقتدار مافوق) در ستون‌های «محور دلالت»، «توضیح» و «ماتریس هم‌نشینی» (پیوست ۳ اسکلت مقاله) نوشته می‌شود — نه در خود کد.

**راهنمای کدگذاری (قواعد روش‌شناختی):**
1. **صامت‌سازی:** صدا پیش از تحلیل قطع می‌شود.
2. **برش‌های پیکربندی (Configuration Cuts):** تغییر معنادار در ترکیب «نگاه + سر + دست» = واحد جدید.
3. **پایایی بین‌کدگذار:** کاپای کوهن ≥ ۰٫۷۵.
4. **کنترل جبر فیزیولوژیک:** دست راست = تکیه‌گاه (ثبات)، دست چپ = کنش‌گر (کانون کینم‌های دست).
5. **ماتریس هم‌نشینی:** دلالت در پیکربندی (هم‌نشینی چند کد) برآمده است.

خروجی کامل کتاب‌کد + راهنما + ماتریس: `shared/output/کتاب‌کد.xlsx`

## ۳. مقالهٔ ۱ — نشانه‌شناسی ساختار کالبدی و زبان بدن (ویدیو، صامت‌شده)

**پنج موقعیت تعاملی منتخب:**
1. دیدار با خانواده‌های شهدا
2. ملاقات دیپلماتیک خارجی
3. دیدار با کارگزاران داخلی
4. سان و رژهٔ نظامی
5. دیدار با شاعران و ادیبان

**واحد تحلیل:** کینم‌های بدنی (body kinemes) در فریم‌های کلیدی + برش‌های پیکربندی (Configuration Cuts) درون توالی‌های ۲–۳ دقیقه‌ای. فرمت شناسهٔ رویداد: `SIT-XXX-YYYYMM-FNN` (مثال: `SIT-DIP-202207-F03`).

### گردش‌کار
```
فیلم‌ها → صامت‌سازی → فهرست‌برداری → انتخاب لحظه‌ها → برداشت فریم/شیت تماس →
کدگذاری در xlsx (۷ مقولهٔ ماتریسی) → اعتبارسنجی (کاپای کوهن ≥ ۰٫۷۵) →
آمار+نمودار → اسکلت مقاله (با پیوست ماتریس هم‌نشینی)
```

### دستورات (از پوشهٔ `tools` اجرا کنید)

```bash
# ۱) فهرست‌برداری همهٔ ویدیوها (مدت، ابعاد، fps) → xlsx + json
python zbd_video.py inventory

# ۲) برداشت فریم‌های معین (برای کدگذاری دقیق)
python zbd_video.py extract --video "فایل.mp4" --times "0:02,0:15,1:30"
python zbd_video.py extract --video "فایل.mp4" --range "0:02-0:30" --step 2

# ۳) شیت تماس (چند فریم کنار هم با برچسب زمان) — برای کدگذاری سریع
python zbd_video.py contact --video "فایل.mp4" --times "0,2,5,8,11,14" --cols 4

# ۴) نمونه‌برداری یکنواخت از کل ویدیو (نمای کلی موقعیت)
python zbd_video.py sample --video "فایل.mp4" --n 24
```

### کدگذاری و تحلیل
```bash
# ساخت برگهٔ کدگذاری خالی با فهرست‌های کشویی (در Python):
python -c "from zbd_sheet import article1_coding_sheet; from zbd_common import A1_OUT; article1_coding_sheet().save(A1_OUT/'کدگذاری.xlsx')"

# سپس مقادیر را در xlsx پُر کنید (فهرست‌های کشویی کد و موقعیت را دارند).

# اعتبارسنجی کدها
python zbd_analyze.py crosscheck --sheet "article1/output/کدگذاری.xlsx"

# آمار تواتر + تقسیم بر موقعیت ارتباطی
python zbd_analyze.py stats --sheet "article1/output/کدگذاری.xlsx" --by-context

# نمودارهای میله‌ای (فارسی)
python zbd_analyze.py charts --stats "article1/output/stats_کدگذاری.json"

# اسکلت کامل مقالۀ فارسی (docx, RTL)
python zbd_analyze.py report --article 1 --out "article1/output/مقاله.docx"
```

## ۴. مقالهٔ ۲ — بازنمایی زبان بدن در صفحهٔ اول (تصویر)

### گردش‌کار
```
صفحهٔ اول‌ها → فهرست‌برداری → شبکهٔ ۳×۳ مرجع → برش عکس‌ها →
شیت مقایسۀ رویداد مشترک → کدگذاری در xlsx → آمار+نمودار → اسکلت مقاله
```

### دستورات
```bash
# ۱) فهرست تصاویر صفحهٔ اول و برش‌ها → xlsx + json
python zbd_frontpage.py inventory

# ۲) ترسیم شبکهٔ ۳×۳ مرجع روی صفحه (برای کدگذاری جایگاه ۹ ناحیه‌ای)
python zbd_frontpage.py grid --image "روزالف_1405-08-15.png"

# ۳) برش ناحیه‌ای از صفحه (مختصات نسبی ۰ تا ۱: x1,y1,x2,y2)
python zbd_frontpage.py crop --image "روزالف_1405-08-15.png" --box "0.2,0.08,0.8,0.35"

# ۴) شیت مقایسۀ ۳(یا بیشتر) صفحه برای یک رویداد مشترک
python zbd_frontpage.py grid3 --images "روزالف.png روزب.png روزج.png"

# ۵) شیت تماس از همهٔ برش‌ها (برای کدگذاری سریع)
python zbd_frontpage.py contact
```

### کدگذاری و تحلیل
```bash
# ساخت برگهٔ کدگذاری تصویر صفحهٔ اول (با فهرست‌های کشویی):
python -c "from zbd_sheet import article2_coding_sheet; from zbd_common import A2_OUT; article2_coding_sheet().save(A2_OUT/'کدگذاری.xlsx')"

# اعتبارسنجی / آمار / نمودار / اسکلت مقاله — دقیقاً مثل مقالهٔ ۱:
python zbd_analyze.py crosscheck --sheet "article2/output/کدگذاری.xlsx"
python zbd_analyze.py stats --sheet "article2/output/کدگذاری.xlsx"
python zbd_analyze.py charts --stats "article2/output/stats_کدگذاری.json"
python zbd_analyze.py report --article 2 --out "article2/output/مقاله.docx"
```

## ۵. دو احتیاط روش‌شناختی (در ابزارها کدگذاری شده)

1. **مقالهٔ ۲:** از یک عکس ثابت، *مسیر/تداوم حرکت* استنباط نمی‌شود. برگهٔ کدگذاری،
   ستون «حالت دست» را به‌جای «حرکت دست» می‌پرسد و محور تحلیل «حالت بدنیِ ثبت‌شده» است.
2. **مقالهٔ ۲:** «انتخاب تصویر» قابل مطالعه است، ولی *نیت سردبیر* بدون شواهد تکمیلی
   (مصاحبه/آرشیو) قابل توضیح نیست — اسکلت مقاله این قید را در بخش «اعتبار و محدودیت» دارد.

## ۶. خودآزمون سریع همهٔ ابزارها
